flashpod - inspect, patch, rehearse and flash early-iPod firmware, and manage the music on it.

Commands:
  flashpod setup                     set up a card step by step
  flashpod inspect TARGET            everything about a card, iPod or image
  flashpod drive partition [--target T]
                                     partition a drive for an iPod (erases it)
  flashpod drive restore IMAGE [DEVICE]
                                     write a card image onto a drive
  flashpod image new IMAGE SIZE      make a blank card image
  flashpod firmware write [--target T] [FIRMWARE]
                                     write firmware into the drive's firmware
                                     partition; nothing else on it changes
  flashpod firmware extract TARGET   copy the firmware partition (or one image) off
  flashpod bootrom arm|disarm [--target T]
                                     arm or clear a disk-mode update
  flashpod patch list                the patch library
  flashpod music list [tracks|artists|albums]
                                     the library: artist/album tree, or flat counts
  flashpod music add [path ...]      add audio files; directories are scanned
                                     recursively; with no paths, a directory picker
  flashpod music remove id|artist|album ...
                                     remove tracks (ids from `flashpod music list tracks`)
  flashpod music init [name]         create iPod_Control + an empty database
  flashpod music rebuild [name]      rebuild the database from the music on the iPod
  flashpod music export, playlist    copy music off; make and edit playlists
  flashpod help recovery             a card or iPod that won't start

A group alone lists its commands (`flashpod music`). The music commands
work on the mounted iPod (auto-detected and confirmed first; --mount names
it) or on a card image (--raw IMAGE). flashpod 1.0 renamed the 0.x
commands: ls is now `music list`, burn is `drive restore`, and so on;
flash is now `drive partition` then `firmware write`.
